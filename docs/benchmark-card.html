How we tested. 649 real tools from 25 MCP servers (GitHub, Grafana, PagerDuty, Jira, Kubernetes, Sentry, Prometheus, VictoriaLogs and more), 111 hand-labeled requests, one run. LLM = Claude Sonnet 5 choosing from the full catalog, prompt cached. Jev = TypeSafe AI's System One decision model. Also tested: Claude Haiku 4.5 (93%, $0.003, 1.8 s), GPT-5 nano (86%, $0.0003, 3.2 s). Oct 2026.
